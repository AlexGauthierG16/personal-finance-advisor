We believe students will control their spending better, because an LLM can turn messy bank statements into clean, categorised transactions in seconds. Today most of them only check their balance, because sorting transactions by hand takes too long. This breaks if the model gets the sums or dates wrong, so we have it write Python that computes every total, checked before it is shown. When a transaction is unclear, it says "not sure" and asks the user. We would know it works if, on three months of hand-categorised statements, it matches at least 90% of our categories and every total is exactly right.
